                  GPU / NPU / CPU / 网络

        贯穿各层：实验复现、性能分析、可观测性、排障

## 建议的起步方式

先选一个能实际运行的训练任务或推理服务，记录完整环境和基线。围绕一次具体执行追踪调用链，遇到不理解的机制再展开专题笔记。每次实验尽量只改变一个变量，并记录失败结果与限制。

底层硬件、算子、编译与强化学习系统的内容，可以在实际工作涉及后独立扩展为专题。
