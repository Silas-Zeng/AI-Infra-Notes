# AI Infra Notes

## 写作约定

每篇文章尽量回答：问题是什么、机制是什么、证据在哪里、结论适用于什么条件。

- 区分原理笔记、源码解读、实验记录与排障复盘。
- 源码解读记录仓库、版本或 commit，避免脱离版本讨论实现。
- 实验记录硬件、软件、工作负载、命令、测量方法和原始结果。
- 标明草稿、已验证和待验证部分；引用资料保留原始出处。
- 更新既有结论时，说明变更原因和验证条件。

## 如何添加内容

1. 从 [文章模板](templates/article.md) 或 [实验模板](templates/experiment.md) 开始。
2. 在对应专题下新建目录，例如 `serving/request-lifecycle/README.md`。
3. 将图片、示例和小型配置放在该文章目录中；大型模型与数据集不进入 Git。
4. 将文章链接、摘要和状态加入专题目录；重要文章也可以放到本页。
