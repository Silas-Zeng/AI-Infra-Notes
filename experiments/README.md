# 实验记录

[返回总览](../README.md)

尚无实验结果。这里存放后续文章对应的可复现实验。

建议每个实验独立建目录，包含：

```text
experiment-name/
├── README.md       # 问题、环境、步骤、结果与限制
├── configs/        # 完整配置
├── scripts/        # 运行与分析脚本
└── results/        # 适合进入 Git 的小型汇总结果
```

从 [实验模板](../templates/experiment.md) 开始；大型日志、模型、数据集与性能 trace 保存在外部，并在记录中说明获取方式。
